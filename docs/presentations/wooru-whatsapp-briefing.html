Formulas, exclusions, and how to interpret the estimate

Meta = marketing count x marketing rate + utility count x utility rate + authentication count x authentication rate + service count x service rate. Counts are delivered and already net of exemptions. Each preset assumes uniform service usage and applies a maximum 1,000 service messages/number exemption before deriving its chargeable counts. Edited counts are not automatically allocated across sellers.

360dialog = numbers x EUR monthly list fee x EUR/INR + entered extra fees. Wati = workspaces x entered INR fee + entered extra fees. Twilio = (inbound + outbound) x USD handling fee x USD/INR + entered extra fees. Direct provider fee = 0; this is not zero integration cost.

Monthly subtotal = Meta + provider + backend + support. Monthly tax = subtotal x tax %. Monthly estimate = subtotal + tax. First-month economic estimate = monthly estimate + setup x (1 + tax %). For Wati, quarterly base subscription cash = workspace fee x workspace count x 3 before taxes; monthly equivalents are not a cash-flow forecast.

12 / LEADERSHIP DECISION · DISCOVERY BEFORE BUILD

Authorize proof, not a network rollout.

First · manual proof

One willing society and essentials basket. Collect comparable quotes, household interest and supplier terms without building a network.

Next · community pilot

Proceed only after a final-price test, fulfillment plan and association service agreement pass pre-agreed gates.

Later · expand

Repeat only if observed savings, fulfillment, opt-in and Wooru's covered operating cost hold across pilots.

Leadership ask: approve discovery and supplier/sponsor/association conversations. Set numeric gates after baselines and quotes; approve implementation separately.

Track comparable landed-price saving, resident opt-in, fulfilled orders, complaints and actual cost per society. No target, supplier quote or contracted income is asserted here.
